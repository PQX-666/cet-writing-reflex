# 重构目标与验收记录

日期：2026-10-03。

## 目标自检

核心目标是帮助学习者独立回应真实考试任务，写出清楚、有解释、连贯且准确的文章。每项设计必须能回答：它让学生产出什么？依据什么反馈？怎样改进？能否在新情境应用？

本次将分散模块归并为今日、课堂、写作、复习四条主入口。保留实际有用的表达回忆，但不再把局部成功升级为整篇作文能力。完整写作、修改版本与保留题成为学习闭环的中心。

## 问题与纠正

| 发现的问题 | 成品处理 |
| --- | --- |
| 20篇旧范文全低于六级最低词数 | 重写逐题原创范文，使用和编辑器相同的计词函数验证；部分题排除给定首句 |
| 2024年6月题错误标成12月 | 来源核对后重新建立题目ID、年月和旧ID别名 |
| 把容貌焦虑、数字鸿沟等负面概念反向赞美 | 按任务目的重写观点与机制，安排独立内容复核 |
| 单复数与搭配错误 | 原创重写、常见错误与边界解释、逐题独立模型校审 |
| 大量重复表达与通用论证 | 80条独特表达，逐题例句、使用边界、机制与具体情境 |
| 空白也判正确、任意答案过关 | 空白不计作答；关键词只允许已知完整变体；未识别不等于错误 |
| 提纲无实际检查、开放题伪自动判定 | 原始产出+对照路线+保存修改，不声称自动判断开放题正确 |
| 关键词、段落、连接词合成100分 | 删除考试评分；事实与语义反馈明确分开 |
| 阅读、自评或一次成功算掌握 | 分别记录阅读、辅助、独立尝试、自评、修订；不生成掌握百分比 |
| 卡片队列不更新、固定复习日程 | 队列随评分与时间更新，简单历史规则公开，不伪称最优记忆模型 |
| 缺乏换题产出与保留评估 | 8道保留题不进入推荐或普通课堂；先写后看，答案浏览留痕 |
| UTC日界线、历史被覆盖 | 中国时区日期和追加事件；原稿与修改稿分别保存 |
| 计时刷新重置或后台漂移 | 持久截止时间，按墙钟时间恢复；结束后需要显式重置 |
| 设置和首次流程不生效 | 级别、时长、焦点进入推荐；保存原稿后完成首次流程 |
| 草稿或修改理由易丢失 | 本机即时保存，版本不覆盖，JSON备份与验证恢复 |
| 来源和审核身份模糊 | 每题公开来源性质与指令改写说明；仅标独立模型校审 |

## 质量与效果的区别

结构、字数、构建及交互检查可以证明产品达到对应的功能要求，不能证明学生考试分数已经提高。产品效果仍需基线、训练后和延迟新题的可靠外部评价。范文经过模型交叉复核；没有宣称真人教师或官方阅卷组审核。

## 本次仍需如实保留的边界

- 范文与讲解是原创教学内容，经过独立模型交叉复核，尚未经过真人四六级教师逐篇审核。
- 真实AI语义反馈需要配置服务端环境变量；本次没有真实密钥，验证的是未配置时的明确提示与核心功能可用性，没有宣称完成外部模型端到端验证。
- 数据保存在当前浏览器本机，不提供账户同步；用户应导出备份，尤其在清理浏览器数据前。
- 8道保留题可用于观察独立应用，尚未建立难度等值与阅卷信度；本次验收不能证明实际考试提分。后续效果研究应采用训练前、训练后和延迟新题，并由不了解训练条件的教师按官方整体标准评价。

## 与原始目标的最终对照

本次把“材料看起来丰富”落实为“有来源的任务、达到字数要求的文章、逐题解释和应用边界”；把“学习看起来完成”落实为“真实产出、可检查的修改和保留的新题”。检索练习、间隔复习与减少提示用于支持这一过程，没有将认知科学研究直接包装成产品提分保证。下一步提高质量的重点是教师外部校审与学习效果验证，而非继续叠加无证据的功能或分数。

## 第二轮：知识库与主题覆盖（2026-10-03）

本轮响应“检查几十条内容是否足以覆盖主题，并实际做好知识库”的要求。上方31项测试、77个构建页面为第一轮验收结果；下表记录知识库扩展后的结果。主导航增加知识库入口。

第一性原理目标是让学生面对任务时，能选择恰当内容、解释作用、写出准确表达并检查适用条件。材料数量、收藏数和即时熟悉感不作为作文能力指标。现有80表达按主主题归类后，学习、科技与人际内容较集中，习惯没有专门主类题，文化与消费任务也不足；详细分布见 [覆盖审计](knowledge-coverage.md)。不能据此承诺几乎所有主题。

新增48个原创知识单元：12功能、6语法、6体裁、24主题；其中18个核心单元。12个主题族各有2个专题，27条来源区分官方大纲、机构题目转录、词典及书籍。真实题意作为任务锚点，教学示例与应用题明确为原创；图表、通知等拓展没有冒充新增完整真题。全部48条经独立模型逐条校审，修正7条的比较维度、搭配或行动清晰度，未标作真人教师或官方审核。与17道普通练习题及35个原表达建立关联，8道保留评估题无直接关联。

## 第三轮：使用手册与中文辅助（2026-10-03）

本轮目标是降低基础薄弱学生的理解门槛，同时保留先尝试、后对照的练习流程。新增网页使用手册 /guide，包含三种起步路线、知识库短练习、课堂四步、写作与修改、复习和新题检验、中文辅助、设计理由、保存备份及常见问题。首页、页脚与相关练习页面提供入口；手册依据实际按钮与数据行为写作，并经独立模型复核。

中文辅助覆盖48个知识单元的结构、例句、对比和练习参考，以及30道题的训练要求、给定首句、80条表达的例句与句型、修改段落、常见错误和103个范文文本段（含书信称呼与署名）。已是中文的内容不重复显示。英文保持主体，中文在对应内容下方用13px较淡文字显示；原错句的释义标明“原句想表达”。知识参考、课堂反馈、表达复习与范文的中文均跟随原有揭示条件，不提前开放保留题答案。原英文题材、范文和来源未改变；没有替学生草稿或历史文本自动生成翻译。

全部48条知识与30题的中文经过独立模型语义校审，重点检查否定、条件、情态强度、可数用法与段落配对；修正了知识用法及四级释义中的六处精度问题。审核身份不等同于真人教师校审。自动覆盖审计验证977项中文字段完整性及103个范文段的对应关系，其中包含已存在中文内容的配对字段，不代表977条独立英文素材。
