## 对现有80表达的结论

现有30题共80个表达，按忽略大小写的text计也有80个不同文本。**80个不同文本不等于80种独立句法结构，更不能据此推出几乎所有四六级作文题都能覆盖。** 一些表达可以跨主题使用，例如“提供可用渠道”“按标准检查方案”；但填入一个短语仍不能保证回答题意、解释机制、选择体裁或处理真实限制。

审计将每个现有题目指定一个主主题，表内数量不重复计算；这是为了观察分布，不是唯一正确分类。社区、伦理、习惯等经常有交叉。以现有数据教学taskKind计算：解释8、比较1、讨论6、提出方法10、描述3、场景应用2。该分布不是历年真题统计，也不能用于预测下一次考试。此前每题expressions已经提供搭配、例句和边界，本次保留原数据，新增结构化知识训练。

## 本次补充了什么

原表达卡主要解决“可以怎么说”。知识单元进一步要求解释“为什么这样说、什么时候适用、为什么另一个说法不成立”，并包含三种不同输出：先无提示回忆，再换场景应用，最后辨析错误或过度概括。参考答案允许合理同义改写，不是必须逐字背诵的唯一答案。

12个功能为：

- `mechanism`：解释原因与机制，本版有9个带此标签单元。
- `example`：用具体例子支持观点，本版有8个带此标签单元。
- `condition`：写清条件与范围，本版有17个带此标签单元。
- `contrast`：按共同标准比较，本版有4个带此标签单元。
- `concession`：承认合理顾虑再回应，本版有5个带此标签单元。
- `solution`：提出可执行行动，本版有16个带此标签单元。
- `evidence`：区分证据与推测，本版有12个带此标签单元。
- `define`：界定核心概念，本版有10个带此标签单元。
- `reader`：回应读者与场景需求，本版有12个带此标签单元。
- `synthesis`：整合论点并回扣任务，本版有4个带此标签单元。
- `precision`：让表达准确适度，本版有16个带此标签单元。
- `sequence`：组织步骤或事件顺序，本版有12个带此标签单元。

功能标签可交叉，不代表12套万能句。核心语法包括主谓一致、名词可数性、动词补足结构、从句与名词短语连接、关系从句、时间与时态。语法单元的边界说明集合名词/整体概念、不同词义等情况，避免简单规则过度推广。

六类体裁训练为议论、提案、报告、经历与反思、视觉信息描述、通知/邀请。图表与通知单元是明确的能力拓展，没有伪装成某场新增完整真题；体裁不以固定三段为统一答案。网页把proposal称为建议信、范文加Dear，并不足以证明原题强制书信格式，因此提案单元要求依据实际Directions决定。

## 关联与测评边界

本库关联17个不同的非测评现有题、35个不同的非测评表达。剩余表达仍可在原表达卡与训练题访问；没有为了凑关联数量硬贴知识标签。 `relatedQuestionIds`、`relatedExpressionIds`均不指向8个evaluation保留题，也不复制这些题的范文或专门答案。主题锚点有时涉及相同领域，但这不使练习成为保留题答案。

外部来源链接本身可能含公开真题、范文或同场题目。禁止关联保留题只能减少产品内直接泄露，不能保证用户从未在外部看过相同主题；测评仍需询问曝光情况，并允许换题。知识单元的文化场景源亦可能指向已有测评主题，产品不应因此把“未关联”宣传成严格未见题实验。

## 验收结果与尚未证明的内容

结构验收通过：48唯一ID、18核心、12功能、6语法、6体裁、24主题、12主题各2单元；全部主题有来源，全部单元的来源/主题/功能引用有效；48个application.reference互不重复，每题criteria至少2条，关联不包含保留题。每个单元有回忆、应用与辨析任务。脚本只证明字段与关联合法，不证明英语自然、来源可信或实际提分。

独立模型代理已逐条只读检查48个单元的英语、用法边界与主题对应性，最后复核未发现明确语法或教学逻辑阻塞。本轮按反馈修正7个单元：比较任务统一共同标准；缺失解释改为添加而非修订；职业练习改为针对弱点选择具体任务；回收建议明确维护执行者；材料清单改在准备时检查；经历例句明确比较设计与读者需求；工作经历表达改得更自然。再次运行`npm run check:content`通过。模型审核不等于真人考试教师审核，也不等于官方评分。新增内容优先补准确性、任务覆盖和不同场景输出；之后需要真实学习者独立写作、延迟回忆、跨主题迁移和教师盲评数据检验效果，不能把完成数或卡片熟悉度直接叫作文能力。

后续应根据实际错误增加内容：先修“读错任务/解释缺中间环节/证据越界/搭配错/体裁信息遗漏”，再决定是否需要更多表达。同一功能至少在不同主题实践，主题更换时要重新判断条件，而不是逐词替换名词。完整作文仍按原题时间、字数和给定首句要求验收，知识练习中的1–3句短输出不冒充完整合格范文。
